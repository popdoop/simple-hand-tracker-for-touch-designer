# simple-hand-tracker
simple hand tracker to be used in terminal
since media pipe for td is cpu intensive this runs in your terminal and runs a lot smother once you run it your camera should pop up and you should be able to see the x and y positions of your index, middle, thumb and wrists.

you use a ocs modual 
don't forget to actually install media pipe since we are still using it. 
these are the default settings
IP: 127.0.0.1
Port: 7000
Camera: 0
Display: enabled
